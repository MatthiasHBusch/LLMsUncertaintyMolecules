# Do LLMs Know When They Are Wrong About Molecules? In-Context Property Prediction with Self-Reported Uncertainty

Code, data and results of the paper

> Matthias Busch et al. *Do LLMs Know When They Are Wrong About Molecules? In-Context Property Prediction with Self-Reported Uncertainty*. arXiv preprint, 2026.

Seven language models (via OpenRouter) predict four molecular properties in context, from 30 to 1,000
labelled examples in the prompt (up to the full training pool), and state a 1-sigma uncertainty with every prediction. The repository
holds the prompts and runners, the raw per-call replies, the splits, the classical baselines (TabPFN,
GP, random forests, Chemprop and MLP ensembles, kNN, trivial), the contamination checks, and the scripts
that turn the replies into every result table, figure and LaTeX table of the paper.

## Layout
- `data/` prepared datasets (`<ds>.csv`: lipophilicity, bace, antiviral, esol), splits
  (`splits/<ds>_v2.json` = context draw 1, `<ds>_v2_draw2/3.json` = context draws 2 and 3), test sets
  (`test_sets/<ds>_v2test150.csv`; `last300` / `random300` = earlier candidate sets)
- `src/` (Python 3.11, Julia)
  - `julia/` the runners that called the API: `Run_ICL.jl` (main experiment, reasoning ladder,
    context draws), `Run_ZeroShot_TestSet.jl` (zero-shot contamination screen), `Probe_Models.jl`
    (effort probe), prompts `Prompts_ICL.jl` / `Prompts_ZS.jl`, shared code `Common.jl`
  - `registry/models_v2.json` model registry (OpenRouter ids, pinned providers, prices of 2026-10-08)
  - `icl_common.py` Python reference of the prompt (`check_prompt_parity.py` diffs it against the Julia runner)
  - `common.py` paths, dataset registry, split loading
  - data preparation: `make_splits.py`, `build_test_sets.py`
  - contamination: `corpus_search.py` (infini-gram corpus search), `summarize_corpus.py`,
    `score_zeroshot.py`, `analyze_zeroshot_testset.py`; `memo45/` statistic and registries of the
    memorisation study the screen follows
  - baselines: `baselines/run_baselines.py`, `features.py`, `analyze_baselines.py`, `selfcheck.py`
  - analysis: `analyze_icl.py`, `selective_prediction.py`, `bootstrap_cells.py`,
    `analyze_calibration.py` (with `v1reuse/uq_methods_eval.py`), `report_icl.py`, `report_extras.py`,
    `mixture_sigma.py`, `similarity_context.py`, `fig_error_concentration.py`, `summarize_probes.py`
    (with `estimate_icl_cost.py`)
  - figures and tables: `make_figs.py` (helpers), `make_figs_paper.py`, `export_tables.py`;
    `verify_paper.py` recomputes every number the paper states
  - `unpack_replies.py` decompresses the gzipped raw records (run it first)
- `results/icl/replies/` one gzipped JSONL per cell
  (`<ds>__<model>__N<size>__<effort>[__d<draw>].jsonl.gz`), one record per call (prompt, cached,
  completion and reasoning tokens, cost, provider, reply text, parsed prediction and sigma)
- `results/icl/*.csv|json` per cell (`cells.csv`), per molecule (`<ds>_permolecule.csv`), selective
  prediction, paired bootstrap, calibration, reasoning ladder (`ladder_cells.csv`), context draws
  (`draws_cells.csv`), mixture sigma, similarity to the context, error concentration
- `results/baselines/` per-cell predictions of every baseline (`<method>__<ds>__N<size>[__s<seed>][__d<draw>].csv`,
  `.meta.json` with settings and library versions), `summary.csv`
- `results/contamination/` zero-shot screen (`zeroshot/`: replies per model and dataset, `cells.csv`,
  per-molecule flags), corpus search (`corpus/`: summaries and the answer cache `cache.jsonl.gz`),
  test-set eligibility / representativeness, training-pool deduplication
- `results/meta/` effort and ICL probes, OpenRouter endpoint snapshots (2026-10-08), context-draw overlap
- `figs/paper/` the figures of the paper (PDF + PNG)
- `tables/` every LaTeX table generated by `src/export_tables.py`, including the per-cell tables
- `docs/EXPERIMENT_DESIGN_v2.md` design and decisions; `docs/CLAIMS.md` every claim of the paper ->
  file -> check (claim ids as printed by `verify_paper.py`)

## Reproduce the analysis from the included replies (no API calls)
    pip install -r requirements.txt
    python src/unpack_replies.py                  # replies -> results/icl/*.jsonl, corpus cache
    python src/analyze_icl.py                     # results/icl/cells.csv, <ds>_permolecule.csv
    python src/baselines/analyze_baselines.py     # results/baselines/summary.csv
    python src/selective_prediction.py            # results/icl/selective_prediction.csv
    python src/bootstrap_cells.py                 # results/icl/bootstrap_cells.csv
    python src/analyze_calibration.py             # results/icl/calibration_*.csv
    python src/report_icl.py --ladder             # results/icl/ladder_cells.csv
    python src/report_icl.py --draws              # results/icl/draws_cells.csv
    python src/report_extras.py                   # results/icl/report_extras.json
    python src/mixture_sigma.py                   # results/icl/mixture_sigma.csv
    python src/similarity_context.py              # results/icl/context_similarity*.csv, figs/paper/figA_similarity
    python src/fig_error_concentration.py         # results/icl/error_concentration*.csv, figs/paper/fig_error_*
    python src/analyze_zeroshot_testset.py        # results/contamination/zeroshot/cells.csv, per-molecule flags
    python src/summarize_corpus.py                # results/contamination/corpus/*.csv
    python src/summarize_probes.py                # results/meta/probe_summary.csv
    python src/make_figs_paper.py                 # figs/paper/*
    python src/export_tables.py                   # tables/*.tex
    python src/verify_paper.py                    # every number of the paper; ends with "DIFF 0"

`verify_paper.py`, `selective_prediction.py` and `make_figs_paper.py` only need the unpacked replies
and the shipped result tables. `report_icl.py` and `analyze_calibration.py` also write Markdown
reports to `docs/`; `make_figs.py` draws the full working figure set into `figs/`.

## Re-running the experiments (API calls, cost)
- **OpenRouter key**: set the environment variable `OPENROUTER_API_KEY`, or put a line
  `OPENROUTER_API_KEY=<key>` into a `.env` file in the repository root (git-ignored). Endpoints and
  prices refer to OpenRouter as of 2026-10-08 (`src/registry/models_v2.json`); models may have changed
  or disappeared since.
- **Julia runners** (`src/julia/*.jl`; Julia 1.11.6; packages CSV, DataFrames, JSON, HTTP and the
  standard libraries Dates, Printf, Random, Statistics) additionally need the in-house library
  `LLMs.jl` / `LLMUtils.jl` / `FileWritingHelpers.jl` (request construction, cost limit, usage
  accounting), which is **not included**. Set the environment variable `LLM_JULIA_LIBS` to the
  directory that holds it. Unpack the replies first (`python src/unpack_replies.py`): the runners
  append to `results/icl/*.jsonl` and skip the calls already stored there. Always dry-run first, e.g.
  `ICL_DRYRUN=1 julia src/julia/Run_ICL.jl` (the environment variables of each runner are listed in
  its header).
- **Baselines** (`python src/baselines/run_baselines.py --help`): TabPFN v3.5 needs `TABPFN_TOKEN` in
  the environment (or a line `TABPFN_TOKEN=<token>` in the `.env`) for the licence check of the weights
  download; the weights are licence-gated and not redistributed. Versions of the baseline runs: see
  `requirements.txt` and the per-cell `.meta.json` files.
- The corpus search (`src/corpus_search.py`) queries the public infini-gram API (no key).

## Datasets
| dataset | molecules | property | source |
|---|---|---|---|
| Lipophilicity | 4,200 | logD at pH 7.4 | MoleculeNet (Wu et al., Chem. Sci. 2018), AstraZeneca data deposited in ChEMBL |
| BACE | 1,513 | BACE-1 pIC50 | MoleculeNet; Subramanian et al., J. Chem. Inf. Model. 2016 |
| Antiviral | 1,006 | SARS-CoV-2 Mpro pIC50 | ASAP Discovery / OpenADMET antiviral potency challenge 2025 (unblinded set, Polaris Hub, `asap-discovery/antiviral-potency-2025-unblinded`) |
| ESOL | 1,128 | measured aqueous solubility logS | ESOL, Delaney, J. Chem. Inf. Comput. Sci. 2004 |

`data/<ds>.csv` are the files as prepared for the screen (row order = source file order); the test
sets have 150 molecules, the training pools 4,042 / 1,355 / 844 / 976 molecules after removing
structures shared with a test molecule (`docs/EXPERIMENT_DESIGN_v2.md` section 2,
`tables/c_b2_datasets.tex`). The datasets remain under the terms of their original sources; please cite
the original publications when using them.
